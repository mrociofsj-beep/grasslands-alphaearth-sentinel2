# Mapping Threatened Native Grasslands

Repository containing the scripts used in the study:

Mapping Threatened Native Grasslands: A Comparative Evaluation of AlphaEarth Embeddings and Sentinel-2

## Contents

gee_scripts/
Google Earth Engine scripts for predictor generation and classification.

statistical_analysis/
Python scripts for model evaluation and variable importance.


## Requirements

Google Earth Engine
Python 3.x
numpy
pandas
scikit-learn
